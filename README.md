# 正修週課表 1.0.2

- 釘選子項沿用原站 `sub`、`with-icon`、書籤圖示樣式。
- 重複 ID／手機選單隱藏／學期連結 display:block 的測試頁已實際驗證：釘選可見、位置在桌面側欄、按鈕在右側且垂直中心一致。
- 真實已安裝 1.0.2 的課表頁已確認完整課名補全成功。修正腳本尚需使用者覆蓋安裝目錄並重新載入，不能只重新整理網站。
- manifest 維持使用者指定的 1.0.2；ZIP 名稱 hotfix1 用於區分修正版。

## 1.0.2 更新

- 本學期課表自動從同站修課成績頁補全完整課名；課號衝突、不同學期或讀取失敗不套用。
- 「熱門服務」上方新增「釘選功能」，學期別旁新增「設定釘選功能」。設定依原選單分類，提供儲存／取消；未儲存或按 Esc 不會改變釘選。

## 1.0.1 更新

- 右上角新增「篩選」，可個別隱藏星期一到日。

## 1.0.0 更新

- 新增「放大視窗」：直接在原頁開啟可關閉的對話視窗，自動分配節次高度；支援 Esc 關閉。1280×720 的合成資料測試可同時呈現 13 個節次，不需捲動整張課表。更小視窗仍可能需要在課表區捲動。
- 每張課程可點選，或以 Tab 聚焦後按 Enter／空白鍵，查看完整資訊。
- 修正原站「節次 × 星期」課表誤判成沒有資料。支援只出現部分星期的欄位，缺少的星期保持空白；固定週課表不虛構日期、不顯示週次選擇。
- 同時保留「日期 × 節次」解析與 AJAX 更新支援。
- 相隔超過 30 分鐘的同科課程不合併，避免長休息被顯示成連續上課。

## 更新既有安裝

解壓縮 1.0.2，將檔案放回原先載入的擴充功能資料夾；在擴充功能管理頁按該擴充功能的重新載入按鈕，確認版本為 1.0.2，再重新整理訊息網課表頁。不要同時啟用兩份版本。若改用不同路徑，先停用舊版，再載入新版資料夾。

## 安裝（Chrome / Edge 電腦版）

1. 解壓縮 `csu-weekly-timetable.zip`，保留解壓後的資料夾。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟「開發人員模式」。
4. 選擇「載入未封裝項目」（或「載入解壓縮」），選取包含 `manifest.json` 的 `csu-weekly-timetable` 資料夾。
5. 在同一個瀏覽器登入 https://portal.csu.edu.tw/ ，開啟個人課表；若已開啟該頁，重新整理一次。

擴充功能自動在個人課表頁啟用，沒有工具列彈出視窗。Codex 內建瀏覽器未在本次安裝或驗證支援；請在 Chrome 或 Edge 使用。其他瀏覽器尚未驗證。

## 使用

- 放大視窗：讓課表獨立於網站側欄顯示；關閉後回到原本頁面位置。
- 點選課程：開啟完整資訊，避免緊湊列高遮住內容。

- 上一週／下一週／下拉選單：選擇整學期內的週次。
- 本週：以台灣日期定位。今天不在課表範圍時按鈕停用，初次顯示第一週。
- 顯示原始表格：隨時切回學校原始列表。
- 網站本學期／下學期：仍使用學校原本的按鈕，資料更新後會自動重排。
- 同一課、同教室、同備註、相鄰節次才合併，卡片標示實際起迄鐘點；其間包含下課休息。
- 週六依原表節次排列，鐘點可能與週間不同，以卡片時間為準。
- 無法解析的課程格保留原文；無法辨識日期時提示查看原始表格。
- 畫面较窄時可在課表區橫向捲動；較長卡片內文可捲動。

## 資料與權限

課表轉換腳本只在個人課表頁啟用；釘選腳本在 `https://portal.csu.edu.tw/*` 啟用，僅在找到左側選單與學期標籤時顯示。新增 `storage` 權限，使用 `chrome.storage.local` 保存功能 ID，不保存帳號、成績或課表，也不同步到雲端。釘選偏好由同一瀏覽器設定檔共用；不存在於目前帳號選單的功能不顯示。

課表頁會使用既有同站登入狀態讀取 `min_stuScoreList.aspx` 一次。HTML 回應可能包含成績，但程式只取學期、課號、課名，不保存或對外傳送回應。不讀取 Cookie 值，不新增 cookies、webRequest 權限或背景服務。課名對照只留在該頁記憶體。未變更學校資料。

已使用截圖所示的星期表頭建立合成測試；尚未取得該帳號實際 DOM 做現場驗證。

內容來源是已登入頁面的 `#stuTimetable`。網站結構若改變，可能需要更新擴充功能。本學期完整課名以修課成績頁同學期、同課號補全；找不到、逾時或切換下學期時保留原名，不猜測。未排課日顯示空白，不另行推論放假或停課。
