# BetterCSU-Portal

在正修科技大學訊息網把個人課表轉成週課表，並加上功能釘選與歷年學分篩選。<br>
它作用在你已登入的 [portal.csu.edu.tw](https://portal.csu.edu.tw/)，不是另一個課表網站，也沒有工具列彈出視窗。


## 開發人員安裝

適用 Chrome 或 Edge 電腦版：

1. 取得含 `manifest.json` 的資料夾：clone 本 repo，或解壓 `BetterCSU-Portal-v1.0.5.zip`
2. 開啟 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 打開「開發人員模式」
4. 選「載入未封裝項目」，指向該資料夾
5. 用同一個瀏覽器登入訊息網，開啟個人課表；頁面已開著就重新整理一次

更新時在擴充功能頁按「重新載入」，再重新整理訊息網。不要同時啟用兩份。若瀏覽器要求確認權限，看過後再繼續。

## 個人課表

開啟「個人課表」後，整學期逐日列表會變成星期 × 節次的週視圖。

- **放大視窗**：課表脫離側欄；按 Esc 或關閉後回到原位置
- **點選課程**：看課號、課名、時間、教室；卡片最多兩行，完整內容在詳情
- **上一週／下一週／下拉選單**：在學期範圍內換週
- **本週**：依台灣日期定位；今天不在課表範圍時按鈕停用，初次顯示第一週
- **顯示原始表格**：切回學校列表
- **篩選**：隱藏星期一到日、整天無課的星期、或目前畫面裡全空的節次。換週或放大時會保留；重新整理後重設。全部隱藏時可按「全部顯示」

同一課、同教室、同備註、相鄰節次才合併。卡片寫實際起迄鐘點，中間休息不會畫成連續上課。週六節次可能與週間不同，以卡片時間為準。無法解析的格子保留原文。

本學期課名會用同站修課成績頁、同學期同課號補全。找不到、逾時或已切下學期時保留原名。網站的本學期／下學期按鈕仍用學校的；資料回來後會重排。

## 釘選功能

訊息網左側「熱門服務」上方會出現釘選列。學期別旁有「設定釘選功能」。

勾選原選單裡的項目後按儲存。取消或按 Esc 不會改已儲存的釘選。設定裡的「重置」會清掉勾選，仍需按儲存才生效。

## 歷年學分

在歷年學分頁可依學期、課別、修課狀況、課名或課碼篩選，可組合條件，可一鍵清除。畫面會顯示符合筆數與表列學分加總。學校的實得學分與平均成績不會被改寫。

## 資料與權限

擴充功能向 Chrome 要求 `storage`，並只在 `https://portal.csu.edu.tw/` 相關頁面執行。

釘選 ID 存在這台電腦的瀏覽器，不同步到雲端，不含帳號、課表或成績。解除安裝即可清除。

補全課名時，會用你已登入的工作階段讀取同站修課成績頁一次。回應可能含成績，程式只取學期、課號、課名，不保存、不外傳。不讀 Cookie 值。

課表與學分篩選都在當頁記憶體處理。學校資料不會被改寫。網站改版後可能需要更新擴充功能。

## 開發

在含 `manifest.json` 的目錄執行：

```sh
node --test tests/core.test.cjs tests/features.test.cjs
```

覆蓋率可加 `--experimental-test-coverage`。合成頁 `tests/browser.html`、`tests/integration.html`、`tests/strict.html` 用假資料，不含真實帳號或課程。打包商店 ZIP：

```sh
./scripts/package.sh
```

產出 `BetterCSU-Portal-v1.0.5.zip`，只含執行檔。
