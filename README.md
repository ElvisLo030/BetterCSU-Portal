# 正修週課表 1.0.1

直接在正修訊息網「個人課表」頁，將整學期逐日表格改成星期 × 節次的週課表。不是獨立課表網站。

## 1.0.1 更新

- 右上角新增「篩選」，可個別隱藏星期一到日。
- 「隱藏無課日」依當週資料移除整天無課的星期。
- 「隱藏空白節次」依目前仍顯示的星期，移除全部無課的節次；保留原節次標籤與連堂範圍，不把課程移到錯誤時間。
- 篩選在切換週次、學期、放大模式時保留，重新整理後重設；不新增儲存權限。全部隱藏時會提示恢復，面板有「全部顯示」。
- 課名在卡片最多顯示兩行，完整內容可點開；詳情視窗加寬，課號、課名、時間及教室分層呈現。原站已截短的課名會註明，無法還原省略內容。
- 已實際操作一般與放大模式下的篩選、空白節次移除、重設，以及長課名詳情。尚未在使用者已安裝的 Chrome 做新版現場驗證。

## 1.0.0 更新

- 新增「放大視窗」：直接在原頁開啟可關閉的對話視窗，自動分配節次高度；支援 Esc 關閉。1280×720 的合成資料測試可同時呈現 13 個節次，不需捲動整張課表。更小視窗仍可能需要在課表區捲動。
- 每張課程可點選，或以 Tab 聚焦後按 Enter／空白鍵，查看完整資訊。
- 修正原站「節次 × 星期」課表誤判成沒有資料。支援只出現部分星期的欄位，缺少的星期保持空白；固定週課表不虛構日期、不顯示週次選擇。
- 同時保留「日期 × 節次」解析與 AJAX 更新支援。
- 相隔超過 30 分鐘的同科課程不合併，避免長休息被顯示成連續上課。

## 更新既有安裝

解壓縮 1.0.1，將檔案放回原先載入的擴充功能資料夾；在擴充功能管理頁按該擴充功能的重新載入按鈕，確認版本為 1.0.1，再重新整理訊息網課表頁。不要同時啟用兩份版本。若改用不同路徑，先停用舊版，再載入新版資料夾。

## 安裝（Chrome / Edge 電腦版）

1. 解壓縮 `csu-weekly-timetable.zip`，保留解壓後的資料夾。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟「開發人員模式」。
4. 選擇「載入未封裝項目」（或「載入解壓縮」），選取包含 `manifest.json` 的 `csu-weekly-timetable` 資料夾。
5. 在同一個瀏覽器登入 https://portal.csu.edu.tw/ ，開啟個人課表；若已開啟該頁，重新整理一次。

擴充功能自動在個人課表頁啟用，沒有工具列彈出視窗。Codex 內建瀏覽器未在本次安裝或驗證支援；請在 Chrome 或 Edge 使用。其他瀏覽器尚未驗證。

## 使用

- 放大視窗：讓課表獨立於網站側欄顯示；關閉後回到原本頁面位置。
- 點選課程：開啟完整資訊，避免緊湊列高遮住內容。

- 上一週／下一週／下拉選單：選擇整學期內的週次。
- 本週：以台灣日期定位。今天不在課表範圍時按鈕停用，初次顯示第一週。
- 顯示原始表格：隨時切回學校原始列表。
- 網站本學期／下學期：仍使用學校原本的按鈕，資料更新後會自動重排。
- 同一課、同教室、同備註、相鄰節次才合併，卡片標示實際起迄鐘點；其間包含下課休息。
- 週六依原表節次排列，鐘點可能與週間不同，以卡片時間為準。
- 無法解析的課程格保留原文；無法辨識日期時提示查看原始表格。
- 畫面较窄時可在課表區橫向捲動；較長卡片內文可捲動。

## 資料與權限

只宣告正修個人課表頁的 content script。沒有 cookies、storage、webRequest、全網站權限、背景服務或外部函式庫。不讀取帳密、不新增 API 請求、不儲存或傳送課表；不修改選課與學校資料。CSS 使用 Shadow DOM，避免影響網站其他部分。移除或停用擴充功能後重新整理即可恢復原站。

已使用截圖所示的星期表頭建立合成測試；尚未取得該帳號實際 DOM 做現場驗證。

內容來源是已登入頁面的 `#stuTimetable`。網站結構若改變，可能需要更新擴充功能。課名若被原站截短，本工具不會猜測完整名稱。未排課日顯示空白，不另行推論放假或停課。
